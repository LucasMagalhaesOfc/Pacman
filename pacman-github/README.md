# Pac-Man Halloween — V5.5 (Java + LibGDX)

Leia [LEIA_PRIMEIRO_V55.md](LEIA_PRIMEIRO_V55.md) para ver as novidades, controles, instalacao, ranking e testes.

No Windows: abra a pasta `pacman-github` no IntelliJ ou use `gradlew.bat lwjgl3:run`.

- Ao iniciar, **digite seu nome** e pressione `ENTER`.
- Use **WASD/setas**, `P` para pausar, `R` apos vencer ou perder para jogar novamente.
- **Seis fantasmas** fogem quando o Pac-Man fica monstro.
- Vitoria ao comer todas as bolinhas; o ranking local guarda apenas vitorias e privilegia pontos por minuto.
- Mapa logico: `assets/maps/mapa_v5.txt`; PNG apenas decorativo.

Teste de logica independente do Gradle: `tests\testar_logica_v55.bat`.
